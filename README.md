## Documentação do Dashboard da Trends

### Siga este passo a passo para a ter o arquivo 100% atualizado 
1. Dentro do VS Code, abra o terminal pressionando as teclas `Ctrl + '` (Ctrl + aspa simples)
2. Faça o pull da branch principal atualizada:
```bash
# garantir que ela esteja no seu ambiente de desenvolvimento
git checkout main

# logo em seguida, puxar todas as atualizações feitas nela
git pull origin main
```
3. Feche o terminal aberto no VS Code
4. Modifique o que for necessário e realize o commit assim que acabar
```bash
git add .

# depois
git commit -m "descrição das modificações"

# por último
git push
```
